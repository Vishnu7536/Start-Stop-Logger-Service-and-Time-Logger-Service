# Time Logger Service

## Project Description

Time Logger Service is a simple application developed using C# and .NET. It automatically records the current date and time at regular intervals and stores the timestamp information in a log file.

The application uses timer-based operations to perform logging automatically without requiring the user to enter the time manually.

It helps users understand timer functionality, background operations, and file handling in C#.

## Features

- Automatically record the current date and time.
- Generate timestamp entries at regular intervals.
- Save time records in a text log file.
- Perform automatic logging.
- Maintain a history of recorded timestamps.
- Use timer-based operations.
- Reduce manual time-recording work.

## Technologies Used

- C#
- .NET
- Visual Studio
- System.IO Namespace
- System.Timers or System.Threading.Timer

## Main Functionalities

### 1. Automatic Time Logging
- Get the current system date and time.
- Generate timestamp entries automatically.
- Record time at predefined intervals.

### 2. Timer Operations
- Execute logging at regular intervals.
- Repeat the logging operation automatically.
- Control the logging interval.

### 3. Log File Management
- Store timestamp information in a text file.
- Append new entries without deleting previous records.
- Maintain a history of logged times.
